# SkillSync

AI-Powered Resume Analysis & Job Matching Platform

## 🚀 Live Demo

[**Try SkillSync →**](https://skillsync-oq1a.onrender.com/index.html)

SkillSync is an AI-powered resume analysis platform designed to help students and job seekers understand how well their resume matches a specific job description.

## 📌 Overview

SkillSync analyzes an uploaded resume, extracts relevant information, compares it with a given job description, and generates an AI-powered assessment including ATS compatibility, job match percentage, skills, missing skills, strengths, weaknesses, and improvement suggestions.

## ✨ Features

- 📄 Resume upload and analysis
- 🤖 AI-powered resume evaluation
- 📊 ATS compatibility score
- 🎯 Job match score
- 🧠 Skill identification
- ⚠️ Missing skill detection
- 💡 Resume improvement suggestions
- 📋 Strengths and weaknesses analysis
- 👤 User login and signup
- 📚 User-specific analysis history
- 📈 Dashboard with recent analyses
- 🔍 View previous resume analyses
